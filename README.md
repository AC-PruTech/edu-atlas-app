# EDU Atlas: iPhone home-screen app

The Education Cloud Data Model Atlas packaged for phones. It installs to the home screen and works offline after the first open.

**Open:** https://ac-prutech.github.io/edu-atlas-app/

**Install on iPhone**
1. Open the link in Safari.
2. Tap Share, then Add to Home Screen.
3. Tap Add.

This repo holds only the built app. Source and tests are kept in a separate private repo.
